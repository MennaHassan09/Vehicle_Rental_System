# Vehicle Rental System

## Project Overview
The Vehicle Rental System is a C# console application designed to manage vehicle rentals. It allows administrators to manage vehicles and customers to rent and return vehicles.

## Features
- **Admin Management:** Sign up and log in as an administrator.
- **Add Vehicles:** Add new vehicles with their IDs, models, types, status, daily rates, late fees, and last service dates.
- **View Vehicles:** Display all registered vehicles.
- **Vehicle Availability:** Check which vehicles are available on a specific date.
- **Maintenance Alerts:** View maintenance alerts for vehicles.
- **Customer Rental:** Allow customers to request vehicle rentals by specifying rental and return dates.
- **Vehicle Return:** Process vehicle returns and calculate rental charges.

## Technologies Used
- C#
- .NET
- Object-Oriented Programming (OOP)
- Console Application

## Project Structure
The project is organized into separate C# files, with each class responsible for a specific part of the system.

- `Program.cs` — Contains the main method, menus, and program flow.
- `Vehicle.cs` — Represents vehicles and their information.
- `Customer.cs` — Handles customer information, rental requests, and vehicle returns.
- `Rental.cs` — Manages rental details, dates, and rental charges.
- `admain.cs` — Handles administrator login and vehicle maintenance alerts.

## How to Run
1. Clone or download this repository.
2. Open the project file (`.csproj`) in Visual Studio.
3. Build the solution.
4. Run the application.
5. Follow the console menus to use the system.
